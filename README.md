# Tuxepedia Archive

A Git-friendly archive of Tuxepedia.

## What's here

- MediaWiki pages exported as individual files
- Uploaded images and sprites
- Export scripts used to generate the archive

## Why

The goal is to make the wiki easier to back up, inspect, mirror, and build on without relying on a MediaWiki server.

## Current export

- 7,671 pages
- 5,382 media files
